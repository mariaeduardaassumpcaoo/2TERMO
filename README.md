## 🌐 HTML

HTML significa **HyperText Markup Language** e é usado para criar a estrutura das páginas da internet.

Com HTML podemos colocar:

- Títulos
- Textos
- Imagens
- Links
- Botões
- Listas

O HTML é a base para criar uma página da Web.

---

## ⚙️ Programação Backend

Backend é a parte do sistema que funciona por trás de um site ou aplicativo.

Ele é responsável por:

- Processar informações
- Receber e enviar dados
- Fazer cálculos
- Controlar usuários
- Se comunicar com o banco de dados

Algumas linguagens usadas no Backend são **Java, Python, JavaScript e PHP**.

---

## 🗄️ Banco de Dados

Banco de dados é onde as informações de um sistema são armazenadas e organizadas.

Por exemplo, podemos guardar:

- Nome de usuários
- Senhas
- Produtos
- Notas
- Pedidos
- Informações de clientes

Um dos sistemas usados para trabalhar com banco de dados é o **MySQL**.
